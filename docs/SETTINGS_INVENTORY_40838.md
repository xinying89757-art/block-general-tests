# 40838 设置项盘点（2026-10-23 实测）

## 入口机制（已打通）

- 区块由多个可编辑子区域组成，每个子区域是 `.backstage-blocksEditor-wrap`，带 `data-blockseditor-type`。
- 每个子区域自带工具条（`roles="widget-settings"`），其中「设置」按钮为 `a.backstage-widgettool-btns`（id 形如 `editorBtn-<settingid>-<uuid>`，齿轮图标）；另一个按钮是「编辑样式」（走 `/phoenix/componentStyle/setPage`，属样式层，不是功能设置）。
- 点「设置」后，设置弹窗渲染在**主页面** DOM 中（`.backstage-dialog.backstage-dialog-widgetsettinsframe`），不是 iframe 内。
- 区块级右侧工具栏 `.siteblocks-setting-operateTools` 是**容器级**操作：ID、容器背景、配色、间距、上移/下移、复制、删除，不属于组件功能设置。

## 与能力模块的映射

- 区域 1 → 能力 `custom-filter-fields`（选择自定义筛选字段）+ 关联能力：筛选逻辑（交集/并集）、筛选触发（手动/自动）、产品范围。
- 区域 2 → 能力 `product-list-display`：分页开关、每页数量、展示字段选择、产品对比开关。
- 区域 3 → 能力 `button-link`：链接地址、文本、新窗口打开。
