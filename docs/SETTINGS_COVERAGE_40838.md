## 实跑结果（2026-10-26，v1.3 产品对比前台效果，报告 report-40838-2026-10-26T07-22-21-466Z）

全量 30 项检查：21 pass / 0 fail / 2 skip（无数据来源组、无轮播）/ 7 record。新增 `pld-compare-front` pass：对比开启 + 勾 Brand 后，预览里 20 个可见对比框，勾两个 oracle 夹具产品（测试产品小何2、测试产品小何1），底部栏计数 2/6、含两个产品名；点 Compare 展开大面板（10 秒轮询 `<table>` 始终 0 行）；点 Inquire 进入询盘表单页，含两产品、Brand 列与各自的属性值。跑后对比恢复为关闭、Brand 恢复为未勾选，页面已保存。

第一轮曾 fail（报告 report-40838-2026-10-26T07-13-48-031Z，20 pass / 1 fail），两个都是检查代码的 bug、不是产品问题：(1) 询盘页刚跳转时 `document.body` 为 null，直接读抛错，改为轮询到 body 有文字再读；(2) 恢复读值取的是弹窗里第一个被勾选的 radio，取到的是分页的“是”而不是对比的“关闭”，误判恢复失败，改为只在“关闭/开启”这一对里找被勾选的。教训：弹窗里有多个 radio 组时，读值必须按组过滤，不能取全局第一个；跳转后的页面要等 body 就绪再读。
